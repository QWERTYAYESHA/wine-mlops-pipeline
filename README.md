# Wine MLOps Pipeline

[![MLOps CI](https://github.com/QWERTYAYESHA/wine-mlops-pipeline/actions/workflows/ci.yml/badge.svg)](https://github.com/QWERTYAYESHA/wine-mlops-pipeline/actions/workflows/ci.yml)

MLOps pipeline for Wine Cultivar Classification using MLflow, GitHub Actions, Makefile automation, and automated quality gates.

## Project Components

- Data loading and stratified train/test split
- Random Forest and Gradient Boosting model training
- MLflow experiment tracking and model registry
- Automated tests and MLOps quality gates
- GitHub Actions CI/CD pipeline
